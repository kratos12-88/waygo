# waygo brand system

Purpose-led interface with independent navigation labels, primary activity layout and reusable logo mark.

## Assets
- `public/brand/logo.png`: original transparent brand mark, used in navigation and favicon.
- `public/style.css`: complete app-specific typography, colour, spacing and responsive component rules.
- `DESIGN.md`: palette and visual direction.

## Usage
Maintain clear space around the mark. Do not distort, add shadows, or recolour individual parts. Use the brand wordmark next to the mark in navigation; use the symbol alone at compact sizes. Sample data labels remain visible.
